# 3x-ui Fork — мультинодовая панель для Xray

Форк 3x-ui с доработками: одна панель для нескольких нод, мультиподписки, карта нод.

Репозиторий: https://github.com/GMNSA/x-ui-Fork

## Основные возможности

- **Управление несколькими нодами** из одной панели:
  - Добавление/редактирование нод, проверка статуса, синхронизация статистики
  - Фоновая проверка статуса и сбор метрик по cron
  - Визуализация нод на карте мира с кластеризацией маркеров

- **Мультиподписка**:
  - Единая подписка, агрегирующая инбаунды с нескольких нод
  - Генерация ссылок с учётом статусов нод и доступных клиентов
  - Быстрое копирование URL подписки

- **Общий дашборд и карта мира**:
  - Агрегированная статистика по всем нодам
  - Интерактивная карта (Leaflet) со стилизацией под тему панели (светлая/тёмная)
  - Маркеры нод со статусами и всплывающими карточками

- **Внешний API для нод** (node-to-node):
  - Защищённый заголовком `X-API-Key`
  - Эндпоинты: `/api/external/server/status`, `/api/external/inbounds/list`, `/api/external/health`
  - Rate limiting для защиты от злоупотреблений

## Установка

### Автоматическая установка

```bash
bash <(curl -Ls https://raw.githubusercontent.com/GMNSA/x-ui-Fork/main/install.sh)
```

После установки панель будет доступна по адресу `http://<HOST>:5050/panel/`

### Ручная установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/GMNSA/x-ui-Fork.git
cd x-ui-Fork
```

2. Соберите проект:
```bash
go build -o x-ui
```

3. Запустите:
```bash
./x-ui
```

## Первоначальная настройка

### 1. Первый вход в панель

После установки откройте браузер и перейдите по адресу:
```
http://ваш-ip:5050/panel/
```

**Учетные данные по умолчанию:**
- **Логин:** `admin`
- **Пароль:** `admin`

**ВАЖНО:** Сразу после первого входа измените пароль администратора!

### 2. Изменение пароля

1. Войдите в панель
2. Перейдите в **Settings → Modify User**
3. Введите новый пароль
4. Нажмите **Update**

### 3. Настройка базовых параметров

Перейдите в **Settings → Panel Settings → General**:

- **Web Port** — порт веб-панели (по умолчанию: 5050)
- **Web Domain** — домен для доступа к панели (опционально)
- **Web Base Path** — базовый путь (по умолчанию: `/`)
- **Session Max Age** — время жизни сессии в минутах (по умолчанию: 360)

### 4. Настройка SSL (HTTPS) — рекомендуется для продакшн

1. Получите SSL сертификат (например, через Let's Encrypt)
2. Перейдите в **Settings → Panel Settings → General**
3. Укажите пути к файлам:
   - **Web Cert File** — путь к файлу сертификата (например: `/etc/ssl/certs/cert.pem`)
   - **Web Key File** — путь к приватному ключу (например: `/etc/ssl/private/key.pem`)
4. Нажмите **Update**
5. Перезапустите панель

## Настройка External API Key

External API Key необходим для безопасного обмена данными между мастер-панелью и нодами.

### На мастер-панели

1. Перейдите в **Settings → Security**
2. Найдите раздел **External API Key**
3. Нажмите **Generate** для создания нового ключа
4. Скопируйте сгенерированный ключ (он будет использован при добавлении нод)

### На каждой ноде

1. Войдите в панель ноды
2. Перейдите в **Settings → Security**
3. Вставьте тот же External API Key, что и на мастер-панели
4. Нажмите **Update**

**Важно:** External API Key должен быть одинаковым на мастер-панели и на всех нодах!

## Добавление нод

### Способ 1: Через веб-интерфейс

1. Войдите в мастер-панель
2. Перейдите в **Nodes** (в боковом меню)
3. Нажмите **Add Node**
4. Заполните форму:
   - **Name** — имя ноды (например: "US Server 1")
   - **Host** — IP адрес или домен ноды (например: `192.168.1.100` или `node1.example.com`)
   - **Port** — порт веб-панели ноды (по умолчанию: 5050)
   - **Protocol** — протокол (`http` или `https`)
   - **External API Key** — ключ, установленный на ноде (см. раздел выше)
   - **Remark** — примечание (опционально)
   - **Enabled** — включить/выключить ноду
5. Нажмите **Update**

### Способ 2: Через скрипт (автоматизация)

Используйте скрипт `scripts/register_node.sh` для автоматической регистрации:

```bash
./scripts/register_node.sh \
  -m master.example.com \
  -n "Node 1" \
  -h node1.example.com \
  -w admin123 \
  -k "YOUR_EXTERNAL_API_KEY"
```

Подробная документация: [scripts/README_REGISTER_NODE.md](scripts/README_REGISTER_NODE.md)

### Проверка подключения

После добавления ноды:

1. Нажмите кнопку **Check** рядом с нодой для проверки статуса
2. Статус должен измениться на:
   - **Online** (зеленый) — нода доступна и Xray работает
   - **Offline** (красный) — нода недоступна или Xray не запущен
   - **Error** (оранжевый) — нода доступна, но Xray в состоянии ошибки

3. Нажмите **Sync** для синхронизации статистики с ноды

## Настройка координат для карты

Чтобы ноды отображались на карте мира:

1. Перейдите в **Nodes**
2. Нажмите **Edit** на нужной ноде
3. Заполните поля (опционально):
   - **Location** — общее описание местоположения
   - **Country** — страна
   - **City** — город
   - **Latitude** — широта (например: `40.7128`)
   - **Longitude** — долгота (например: `-74.0060`)
4. Нажмите **Update**

Можно найти координаты на [Google Maps](https://www.google.com/maps) — кликните правой кнопкой на нужное место и скопируйте координаты.

## Создание мультиподписок

Мультиподписка позволяет объединить клиентов с нескольких нод в одну подписку.

### Создание мультиподписки

1. Перейдите в **Multi-Subscriptions**
2. Нажмите **Add**
3. Заполните форму:
   - **Name** — имя мультиподписки (например: "All Nodes Subscription")
   - **Sub ID** — идентификатор подписки (оставьте пустым для автогенерации)
   - **Node IDs** — JSON массив ID нод (например: `[1,2,3]`)
   - **Remark** — примечание (опционально)
   - **Enabled** — включить/выключить
4. Нажмите **Update**

### Получение URL подписки

1. В списке мультиподписок найдите нужную
2. Нажмите на иконку **копирования** в колонке Actions
3. URL будет скопирован в буфер обмена

Формат URL:
```
http://ваш-домен:2096/sub/SUB_ID
```

или

```
https://ваш-домен:2096/sub/SUB_ID
```

### Настройка подписок

Перейдите в **Settings → Subscription Settings**:

- **Sub Enable** — включить/выключить подписки
- **Sub Port** — порт для подписок (по умолчанию: 2096)
- **Sub Path** — путь для подписок (по умолчанию: `/sub/`)
- **Sub Domain** — домен для подписок (опционально)
- **Sub Encrypt** — шифрование подписок (Base64)
- **Sub Show Info** — показывать информацию на странице подписки

## Использование карты мира

1. Перейдите в **Map** (в боковом меню)
2. На карте отобразятся все ноды с указанными координатами
3. Цвет маркеров:
   - Зеленый — нода онлайн
   - Красный — нода оффлайн
   - Оранжевый — ошибка
4. Кликните на маркер для просмотра информации о ноде
5. При большом количестве нод маркеры автоматически группируются в кластеры

## Мониторинг и статистика

### Дашборд

Главная страница показывает агрегированную статистику по всем нодам:
- Общее количество клиентов
- Общий трафик (входящий/исходящий)
- Статус Xray на всех нодах
- Использование ресурсов (CPU, память, диск)

### Статистика по нодам

1. Перейдите в **Nodes**
2. Нажмите **Sync** для обновления статистики
3. Статистика обновляется автоматически каждые 2 минуты (фоновые задачи)

## Дополнительные настройки

### Настройка Telegram бота

1. Перейдите в **Settings → Telegram Bot**
2. Включите **Enable Telegram Bot**
3. Укажите **Bot Token** (получите у [@BotFather](https://t.me/BotFather))

5. Нажмите **Update**

1. Перейдите в **Settings → LDAP**
2. Включите **Enable LDAP**
3. Заполните параметры подключения к LDAP серверу
4. Нажмите **Update**

## API для оркестраторов

### Healthcheck эндпоинт

Для Kubernetes, Docker и других оркестраторов доступен healthcheck:

```bash
curl -H "X-API-Key: YOUR_API_KEY" \
  https://your-node:5050/api/external/health
```

Ответ:
```json
{
  "status": "healthy",
  "timestamp": 1234567890
}
```

### Внешний API

Все внешние API эндпоинты требуют заголовок `X-API-Key`:

- `GET /api/external/server/status` — статус сервера и метрики
- `GET /api/external/inbounds/list` — список всех инбаундов
- `GET /api/external/health` — healthcheck для оркестраторов

Пример:
```bash
curl -H "X-API-Key: YOUR_API_KEY" \
  https://your-node:5050/api/external/server/status
```

## Устранение неполадок

### Нода не подключается

1. Проверьте, что нода доступна по указанному адресу и порту
2. Убедитесь, что External API Key совпадает на мастер-панели и ноде
3. Проверьте файрвол — порт должен быть открыт
4. Проверьте логи: `tail -f /root/x-ui/3xui.log`

### Подписка не работает

1. Убедитесь, что подписки включены в настройках
2. Проверьте, что хотя бы одна нода в мультиподписке включена и онлайн
3. Проверьте, что на нодах есть клиенты с указанным Sub ID
4. Проверьте порт подписок (по умолчанию: 2096)

### Карта не отображает ноды

1. Убедитесь, что у нод указаны координаты (Latitude и Longitude)
2. Проверьте, что координаты указаны в правильном формате (числа с точкой)
3. Обновите страницу карты

### Ошибки при синхронизации

1. Проверьте статус ноды (кнопка **Check**)
2. Убедитесь, что External API Key правильный
3. Проверьте логи на ноде: `tail -f /root/x-ui/3xui.log`

## Что изменено по сравнению с исходным 3x-ui

- Добавлены модели `Node`, `NodeStats`, `MultiSubscription`
- Добавлены сервисы и контроллеры:
  - `NodeService`, `NodeController` (`/panel/api/nodes/*`)
  - `MultiSubscriptionService`, `MultiSubscriptionController` (`/panel/api/multi-subscriptions/*`)
  - `DashboardService`, `DashboardController` (`/panel/api/dashboard/*`)
  - `ExternalController` (`/api/external/*`)
- Фоновые задания (`cron`) для мониторинга и синхронизации
- UI-страницы: `panel/nodes`, `panel/multi-subscriptions`, `panel/map` + пункты меню
- Расширенное логирование ошибок в `NodeClient`
- Кластеризация маркеров на карте при большом количестве нод
